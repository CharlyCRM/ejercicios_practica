# Cocina — borrador de modelado

Planteé este ejercicio para representar recetas e ingredientes con clases de Python. El diseño más amplio incluía inventario, estaciones y asignación de pedidos, pero no está implementado como aplicación.

## Lo que existe

`modelos.py` contiene `Ingrediente` y `Receta`; `excepciones.py`, un primer planteamiento de error. Son piezas iniciales, no un simulador completo.

## Lo que quedaba por construir

Inventario, estaciones, pedidos, estrategias de asignación y persistencia eran propuestas de continuación. No existe un `main.py` ni los módulos necesarios para ejecutar los comandos de simulación del diseño original.

La carpeta permite revisar ese primer modelado. No implica que estén resueltas las reglas de stock, disponibilidad, priorización o guardado. Esta documentación distingue el objetivo del estado real, sin añadir funcionalidades ni pruebas.
