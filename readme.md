# Mi cuaderno de práctica de Python

Aquí reúno ejercicios de distintas etapas: lógica, programación orientada a objetos, datos y pequeñas aplicaciones de consola. Es un cuaderno de trabajo, no una única aplicación terminada.

## Orientarse

- `ejercicios_poo/`: clases y objetos.
- `ejercicios_programacion/` y notebooks de la raíz: problemas de Python y pandas.
- `algebra_lineal/`: vectores y PCA.
- `agenda_contactos.py`, `tienda_interactiva.py` y otros scripts: prácticas independientes.
- `biblioteca_inteligente/`: ejercicio de entidades y préstamos, todavía parcial.
- `cocina_inteligente/`: diseño de recetas e ingredientes, con implementación inicial.

Los README de estas dos carpetas distinguen lo que existe de lo que se planteaba desarrollar.

## Revisar o ejecutar

Puedes leer los notebooks en GitHub. Antes de ejecutar, revisa imports, rutas y celdas: no todos usan las mismas dependencias ni están completos. `requirements.txt` no garantiza que cualquier archivo funcione.

Trabaja en un entorno virtual y con ejemplos. Algunos scripts escriben archivos; no hay un comando único ni pruebas que validen todo el repositorio.

## Por qué lo conservo

Me permite seguir cómo aprendí a plantear problemas y dividirlos en funciones y clases. Las partes sin terminar pertenecen a ese proceso, no son proyectos de producción.
